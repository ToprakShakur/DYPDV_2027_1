# Proyecto 2D - Práctica 3 (Unity)
 
## Descripcion
Este proyecto corresponde a la **Práctica 3 de Ayudantía en Unity 2D**, donde se 
introducen conceptos de Movimiento Avanzado,Frenado y Direccion del Personaje.
 
## Requisitos 
- Unity Hub instalado.
- Repositorio del curso configurado.
- Spritesheet proporcionado o descargado.
 
## Pasos para ejecutar 
1. Clonar el repositorio:
```bash
git clone <https://github.com/ToprakShakur/Programacion_Videojuegos.git>```
2. Abrir Unity Hub y seleccionar el proyecto de la carpeta
	Programacion_Videojuegos/Ayudantia/Practica03_2D
3. Ejecutar la escena desde el editor 
	Demostracion
	- El personaje esta creado como Prefab con:
	- Sprite Renderer
	- BoxCollider2D
	- Rigidbody2D

	- Se detectan inputs básicos:
		- Movimiento laterales (flechas).
		- Salto (barra espaciadora) = Salto detectado
	- La actualizacion ahora mejora en el movimiento,frenado progresivo,cambio de direccion suave.
