# Proyecto 2D - Práctica 1 (Unity)
 
## Descripcion
Este proyecto corresponde a la **Práctica 1 de Ayudantía en Unity 2D**, donde se 
introducen conceptos básicos de sprites, colisiones y detección de inputs.
 
## Requisitos 
- Unity Hub instalado.
- Repositorio del curso configurado.
- Spritesheet proporcionado o descargado.
 
## Pasos para ejecutar 
1. Clonar el repositorio:
```bash
git clone <https://github.com/ToprakShakur/Programacion_Videojuegos.git>```
2. Abrir Unity Hub y seleccionar el proyecto de la carpeta
	Programacion_Videojuegos/Ayudantia/Practica01_2D
3. Ejecutar la escena desde el editor 
	Demostracion
	- El personaje esta creado como Prefab con:
	- Sprite Renderer
	- BoxCollider2D
	- Rigidbody2D

	- Se detectan colisiones con otros objetos y se imprimen en consola: Colision con: Plataforma
	- Se detectan inputs básicos:
		- Movimiento horizontal (flechas) = Movimiento horizontal: 1
		- Salto (barra espaciadora) = Salto detectado
